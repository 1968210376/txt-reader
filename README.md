# TXT 小说朗读工具

一个网页版小说朗读工具，支持卡拉OK式文字跟随高亮。

## 功能特点

- 支持选择文件夹或单个文件
- 卡拉OK式文字高亮（当前段落绿色高亮）
- 进度条实时显示
- 上一章/下一章快速切换
- 播放/暂停控制
- 语速和音调调节
- 多种中文语音选择（默认晓晓）
- 支持手机端使用

## 使用方法

### 电脑端
1. 点击"选择文件夹"加载整个文件夹的txt文件
2. 或点击"选择文件"选择单个或多个txt文件
3. 选择章节后点击"播放"开始朗读

### 手机端
1. 点击"选择文件"选择txt文件
2. 点击"播放"开始朗读
3. 使用Edge浏览器可获得更好的中文语音效果
